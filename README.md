# Ragnarok Zero Wiki

Bilingual EN/FR community wiki focused on **Ragnarok Zero**.

## Data rule
Gameplay data must be verified specifically for Ragnarok Zero. iRO Classic / Pre-Renewal / Renewal may be used only as visual or structural references, never as gameplay-data sources.

## Monster data attribution
Monster identity, level, race, size, property and navigation data come from the Ragnarok Zero client supplied for this project. The additional monster stat overlay uses the open **RagnaDex** API and imports only fields explicitly marked by that source as Zero-verified (`zero_felder`). Unverified Renewal fallback values are intentionally ignored.

## Website
The static site is served from `index.html` and is ready for GitHub Pages.
